CrossInk Stats Forge

Upload reading-stats files from CrossInk, CPR-vCodex, and INX. Choose which source to keep when a book shows up more than once. Get back one merged set of CrossInk files.

⚠

Reverse-engineered, not official. These formats come from studying real device exports, not manufacturer documentation. Confidence varies by field — anything still uncertain is flagged on the book itself, below.

Back up your device's .crosspoint folder before copying anything back. Sessions, total time, and pages are written into both the global file and each book's own file.

1. Upload your stats files

Each format is detected automatically — just make sure you're grabbing the right file from each firmware:

CrossInk The per-book stats file — named stats_v5.bin, found inside that book's own folder (not the all-time global_stats.bin, and not a dated backup export).
INX The per-book stats file — named statistics.bin, found inside that book's own folder.
CPR-vCodex The stats_exported file from the firmware's exports folder — this one covers every book in a single file.

Multiple files at once, any mix of the formats above

2. Review & merge

Every book found across your uploads, grouped by title. When a book appears in more than one file, choose which numbers to keep — or type your own.

Upload some files above to see books here.

3. Global stats (auto-computed)

The all-time total across every book above — built automatically, nothing to fill in.

"Books completed" only counts books we have a confirmed completion signal for (currently: CPR-vCodex imports where the book was marked finished). If a book was actually finished elsewhere, this count may undershoot — you can still fix it on-device later.

4. Download

One global_stats.bin plus one stats.bin per book. Drop the global file at the root of your stats folder, and each book's file into that book's own cache folder.

Formats reverse-engineered from real CrossInk / CPR-vCodex / INX exports. No affiliation with the CrossInk, CrossPoint, or vCodex projects — use at your own risk, and always keep a backup of your SD card's .crosspoint folder.
